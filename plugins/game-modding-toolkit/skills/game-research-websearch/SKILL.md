# Research for visual development
Reuse local source, dependency versions and project notes first. Search primary engine/framework documentation and official repository issues/releases for the exact version and question. Verify generation models, schemas and prices before use. Keep URLs, relevant facts and limitations in project notes. An upstream modding example can inform a technique, but does not determine the user's project architecture. Do not publish findings externally unless authorized.
